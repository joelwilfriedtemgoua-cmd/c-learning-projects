# Calculatrice GTK4

Cette calculatrice est une version modulaire en C avec GTK4.

## Structure
- `operations/` : logique mathématique
- `disposition/` : affichage et boutons
- `calculatrice_complete.c` : application principale
- `style.css` : style visuel

## Compilation
```bash
cd calculator-gtk4
make
./calculatrice
```

## Fonctionnalités
- Addition
- Soustraction
- Multiplication
- Division
- Modulo
- Racine carrée
- Pourcentage
- Puissance
- Affichage moderne
